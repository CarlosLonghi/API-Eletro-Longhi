# ExecPlans

Stores executable feature specifications — see `.claude/PLANS.md` for the full spec and when to write one.

## Usage

```bash
cp .claude/execplans/TEMPLATE.md .claude/execplans/YYYY-MM-DD-feature-name.md
```

Fill it out as you work; commit it alongside the feature. Naming: `YYYY-MM-DD-feature-name.md`.
